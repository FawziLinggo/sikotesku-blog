Dokumen Karier memungkinkan kamu menyimpan satu CV aktif agar dapat digunakan kembali pada Karier 31 dan layanan karier lain. CV tetap privat dan tidak dikirim untuk review tanpa persetujuanmu.

Gunakan hanya CV milikmu sendiri.

## Format CV yang diterima

Pada alur yang diverifikasi 28 Agustus 2026, Dokumen Karier menerima:

- file PDF;
- maksimal 5 MB;
- maksimal 3 halaman;
- tidak diproteksi password;
- struktur file yang dapat divalidasi.

File kosong, format selain PDF, atau dokumen rusak akan ditolak.

## Satu CV aktif

Profil menampilkan tepat satu CV aktif. Kamu dapat:

- upload pertama;
- mengganti CV;
- mengunduh CV aktif;
- menghapus dari Dokumen Karier.

Saat mengganti, sistem membuat versi baru. Hal ini membantu menjaga submission review yang sudah berjalan tetap menunjuk file yang kamu setujui sebelumnya.

## Mengganti CV tidak mengubah review aktif

Jika sebuah versi sudah dikirim untuk review, mengganti CV profil tidak diam-diam mengganti dokumen pada antrean tersebut.

Ini penting agar Tim dan peserta membahas file yang sama. Periksa nama file serta versi sebelum memberi consent.

## Paket dan penggunaan CV

Paket Mulai dapat memakai CV untuk aktivitas mandiri. Paket Fokus dan Didampingi dapat menyediakan alur Review CV setelah aktivitas persiapan melamar terbuka.

Benefit dapat berubah; lihat [perbandingan paket Karier 31](/artikel/paket-karier-31-mulai-fokus-didampingi/).

## Consent tetap diperlukan

Menyimpan CV tidak sama dengan mengirim CV. Ketika meminta review, kamu perlu memilih versi dan menyetujui penggunaan untuk proses tersebut.

Jangan memberi persetujuan bila:

- file bukan milikmu;
- CV masih memuat data yang tidak perlu;
- posisi tujuan salah;
- kamu belum membaca ketentuan;
- file yang tampil bukan versi terbaru.

## Kurangi data sensitif

CV umumnya tidak memerlukan:

- nomor identitas pemerintah;
- data rekening;
- password;
- dokumen keluarga;
- alamat rumah sangat rinci;
- tanda tangan digital yang dapat disalahgunakan;
- data orang lain.

Masukkan informasi kontak secukupnya untuk kebutuhan melamar.

## Periksa status file

Kartu Dokumen Karier dapat menampilkan:

- nama file aman;
- nomor versi;
- jumlah halaman;
- ukuran;
- tanggal upload;
- apakah perlu diperbarui;
- kompatibilitas untuk kebutuhan review tertentu.

Gunakan status "perlu diperbarui" sebagai pengingat untuk mengecek isi, bukan berarti file otomatis salah.

## Hapus dengan memahami konsekuensi

Menghapus CV dari profil menghilangkan versi aktif untuk penggunaan berikutnya. Versi yang sudah dikirim untuk review dapat dipertahankan sampai proses tersebut selesai.

Jangan menghapus saat upload masih berjalan. Tunggu pesan sukses atau gagal.

## Checklist sebelum upload

1. Nama dan kontak benar.
2. Tidak ada data sensitif berlebihan.
3. Pengalaman tidak dibuat-buat.
4. Posisi tujuan relevan.
5. PDF maksimal tiga halaman dan 5 MB.
6. File tidak berpassword.
7. Nama file profesional dan tidak memuat nomor identitas.

[Cara membuat CV fresh graduate](/artikel/cara-membuat-cv-fresh-graduate/) dapat membantu merapikan isi.

## Hubungan dengan Karier 31

Pada aktivitas persiapan melamar, Karier 31 dapat meminta CV aktif sebelum membuka arahan atau submission review. Jika belum ada file, lengkapi Dokumen Karier lebih dulu.

Laporan program tidak menampilkan isi CV secara publik.

## Ringkasnya

Dokumen Karier menyimpan satu CV aktif berformat PDF maksimal 5 MB dan 3 halaman. Pergantian membuat versi baru, sedangkan pengiriman review memerlukan consent terpisah.

Kelola file melalui [Dokumen Karier Sikotesku](https://sikotesku.com/profile#career-document).
